# RP Portals (`rpportals`)

Порталы семейства RP (Forge 1.20.1, требует RP Core ≥ 0.8.0). Ставит ведущий: предмет «Портал» во вкладке
«RP: разное». С меткой ведущего в руке (любой предмет из `rpcore:gm_markers`) виден якорь и рамка плоскости
(розовая — связан, красная — нет; белая стрелка — «лицо»), ПКМ по якорю — окно настроек.

## Настройки
- **Имя, «ведёт в»** — связь по имени. Связали A → B, а у B своей связи нет — B сразу ведёт в A (пара). Можно
  односторонний и цепочкой. Портал с именем — ещё и точка прибытия для невидимой пластины RP Core.
- **Плоскость:** поворот лица, ширина, высота, сдвиги; форма — прямоугольник, скругление, овал.
- **Вид:** цвет / та сторона вживую / невидимый; непрозрачность, свечение, туман (как в Dark Souls), рябь, обод и
  его цвет. Заготовки: «проём», «туман», «портал» (овал, обод, живой вид).
- **Живой вид:** блоки и сущности «коробки» перед порталом-целью (ширина + 1,5 по бокам, глубина `viewDepth`)
  рисуются за плоскостью вживую, дальше — туман цвета портала. Нужно, чтобы цель была в том же измерении и в
  пределах прорисовки; иначе — цвет. Модель коробки пересобирается, только когда в ней что-то поменялось.
- **Проход:** только с лица / с обеих сторон; игроков / всех (остальных сущностей переносит сервер).
- **Включение:** просто войти / держать ПКМ (кольцо у прицела, потом проход открыт `openSeconds`, двери в проёме
  открываются для всех и закрываются сами).

## Как устроен переход
Бесшовно в пределах измерения: клиент сам переносит игрока в момент пересечения (место, взгляд, скорость, плавность
кадра), сервер ставит его туда же и подтверждает «телепортом на 0 относительно» — без рывка. Пока игроки рядом
(32 блока), сервер держит чанки цели загруженными. В другое измерение — обычный перенос с затемнением.

## Отрисовка
Свой шейдер `rpportals:portal`. Без шейдерпака — после полупрозрачных блоков; с шейдерпаком Oculus — после его
финального прохода, поверх кадра (без теней и света шейдерпака).

## Сборка
`JAVA_HOME=<JDK 17> ./gradlew build` (jar RP Core — в `libs/`). Проверка загрузки: `./gradlew runGameTestServer`.

Не проверено в игре (0.1.0, 23.10.2026).
